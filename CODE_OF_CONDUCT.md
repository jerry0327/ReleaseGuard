# Code of Conduct

ReleaseGuard welcomes technical disagreement and security scrutiny. Participation in project spaces requires professional, good-faith collaboration.

Do not harass, threaten, discriminate against, or deliberately expose private information about contributors. Do not publish unpatched vulnerability details in public project channels when a private reporting path is available.

Maintainers may edit or remove content and restrict participation when behavior materially disrupts the project or puts people or users at risk. Enforcement decisions should be proportionate, documented when appropriate, and focused on project safety.
